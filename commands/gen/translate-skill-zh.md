将指定的 Skill 目录翻译为中文版本，保存到同级的 `{原目录名}-zh` 目录下，保持完全相同的目录结构和文件组织。

## 参数

要翻译的 Skill 目录路径：$ARGUMENTS

如果参数只是一个目录名（如 `java-spring-boot`），则默认基础路径为 `.claude/skills/`。

## 翻译规则

请严格按照以下规则对不同类型的文件执行翻译：

### 1. Markdown 文件（`.md`）

- **正文内容**翻译为中文
- **关键英文术语**保留原文不翻译（如 Spring Boot、JPA、Hibernate、JUnit、Mockito、REST API、OAuth2、JWT、Testcontainers、EntityGraph、DTO 等技术专有名词）
- **代码块中的代码**不翻译，仅翻译代码块内的**注释**部分
- **表格内容**翻译为中文
- **frontmatter（YAML 头部）** 中的 `description` 等描述字段翻译为中文，`name`、`version`、`enum` 值等结构性字段保持不变

### 2. YAML 文件（`.yaml` / `.yml`）

- **仅翻译注释**（`#` 开头的行）
- **不修改任何键名、键值、缩进或格式**
- 保持文件结构完全不变

### 3. JSON 文件（`.json`）

- JSON 标准不支持注释，通常**原样保留**
- 如果 JSON 中有 `title`、`description` 等面向用户的字段，可以翻译其值
- **不修改结构、键名或格式**

### 4. Python 文件（`.py`）

- **仅翻译注释**（`#` 开头的行）和 **docstring**（`""" """` 中的文档字符串）
- **`print()` 中面向用户的提示文字**翻译为中文
- **不修改任何代码逻辑、变量名、函数名、类名**
- 保持代码格式和缩进不变

### 5. 其他文件类型

- 配置类文件（`.properties`、`.toml` 等）：仅翻译注释
- 纯代码文件（`.java`、`.js`、`.ts` 等）：仅翻译注释，不改动代码
- 二进制或数据文件：原样复制

## 执行步骤

1. **探索源目录**：列出源 Skill 目录下所有子目录和文件
2. **创建目标目录**：在同级位置创建 `{原目录名}-zh` 目录及所有子目录
3. **逐文件翻译**：按上述规则读取每个文件、翻译并写入目标目录
4. **验证完整性**：确认目标目录的文件数量和结构与源目录一致
5. **输出汇总**：以表格形式列出所有文件及其翻译策略
